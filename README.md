# Instagram Reel Archiver & AI Analyzer Bot

A 24/7 automated Telegram Bot (`@Instadevtoolsbot`) that:
1. Downloads Instagram Reels with `yt-dlp`.
2. Analyzes video and audio speech using Gemini AI (`gemini-2.5-flash`).
3. Extracts tool names, detects GitHub links, and writes a Hinglish AI summary.
4. Archives the video to Google Drive and appends metadata to Google Sheet.
